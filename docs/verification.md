## 浏览器已覆盖的行为

1. 直接以本地文件方式打开 index.html，输入虚构 Key 后连接。
2. 相同盘口跨公司横向对齐，让球主客赔率上下排列。
3. 香港盘与马来盘切换，不重新建立连接。
4. 上下两项独立涨跌高亮；马来盘跨符号时仍按十进制实际赔率判断，约 3 秒恢复。
5. 市场、阶段、比赛类型筛选不重连。
6. 主动断开后保留报价。
7. 刷新后 Key 清空，不恢复连接。
8. 测试期间没有持久化 Key 的存储写入。
9. 浏览器没有捕获到页面脚本异常。
10. 异常断线后重新建立连接，原表保留，新消息继续更新对应报价。
11. 马来盘缺失时显示占位符，不回退为香港盘或自行换算。
12. 205 条盘口分成两页，单页最多 200 条，翻页不丢失缓存报价。
13. 比赛、盘口、公司及报价缓存有明确上限；达到上限后已有报价仍可更新。超长消息及字段不保留，未使用字段不进入缓存。
